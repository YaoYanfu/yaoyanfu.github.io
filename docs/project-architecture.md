# Yves' Notebook — 项目架构与 Live2D 看板娘实现

## 概述

- **域名**: `yvesyao.com`
- **框架**: Docusaurus 3.10.1 (`@docusaurus/core`)
- **前端库**: React 19 + React DOM 19
- **构建器**: Rspack（`@docusaurus/faster`，替代 Webpack）
- **主题预设**: `@docusaurus/preset-classic`（包含文档、博客、搜索等插件）
- **包管理器**: npm
- **Node 最低版本**: ≥20
- **仓库路径（本地）**: `E:\my-notebook`

## 二、配置文件说明

### docusaurus.config.js（中央配置枢纽）

配置是标准的 Docusaurus ESM 模块，使用 JSDoc 类型注解。关键字段：

| 字段 | 作用 |
|------|------|
| `title` / `tagline` / `favicon` | 站点元信息 |
| `url` / `baseUrl` | 生产域名和路径前缀 |
| `future.v4: true` | 启用 Docusaurus v4 兼容模式 |
| `onBrokenLinks: 'throw'` | 断链时报错（不是警告） |
| `plugins` | 加载自定义插件数组，当前包含 `./plugins/live2d-plugin` |
| `presets['classic']` | 声明文档（docs）、博客（blog）、主题（theme → customCss） |
| `themeConfig.colorMode` | `defaultMode: 'dark'`，强制暗色模式，用户可切换 |
| `themeConfig.navbar` | 顶部导航：Notebook（docs）、Blog、GitHub（外链） |
| `themeConfig.footer` | 底部：导航链接 + GitHub 链接 + 版权 |
| `themeConfig.prism` | 代码高亮：亮色用 GitHub，暗色用 Dracula |

### sidebars.js

配置 `tutorialSidebar` 为 `autogenerated` 模式，Docusaurus 自动扫描 `docs/` 目录结构生成侧边栏菜单。不需要手动列出每个文件。

## 三、全局样式体系 (src/css/custom.css)

整体设计风格是"Moonshot-inspired Dark Minimalist"。核心特征：

- **背景**: `#000000` 纯黑，加 60px 间距网格线纹理（`body::before` 伪元素），网格是从顶部径向渐隐的 mask
- **导航栏**: 半透明毛玻璃效果 `backdrop-filter: blur(20px) saturate(180%)`，56px 高度
- **卡片**: 玻璃拟态（`rgba(255,255,255,0.03)` 背景 + 极淡边框），hover 上浮 + 渐变阴影
- **按钮**: 主按钮蓝紫渐变 `#4f6ef7 → #7c5cfc`，次按钮透明描边
- **自定义滚动条**: 6px 宽，半透明白色滑块
- **动画**: `@keyframes` 定义了 fadeInUp、fadeIn、shimmer、float、pulse-glow
- **CSS 变量**: 通过 `:root` 暴露的颜色/字体/间距变量复用于 Docusaurus 官方组件（导航、侧边栏、TOC、搜索框等）

## 四、看板娘实现（CHIE 默认 + Live2D 回退）

### 当前方案

主页默认使用 **CHIE CSS 分层动画模型**。角色由透明 WebP、React 状态和 CSS 动画组成，不依赖 Cubism SDK、WebGL 或外部模型 CDN。原有 oh-my-live2d 代码保留为手动回退方案，但默认构建不会注入或下载它。

```
浏览器打开主页
    │
    ├─ 读取 customFields.mascotMode
    │
    ├─ chie（默认）
    │    └─ HomeChieMascot
    │         ├─ 按视口选择：全身 / 头像 / 隐藏
    │         ├─ 首次只加载 idle 或头像 WebP
    │         ├─ 空闲时预载表情与眨眼素材
    │         └─ CSS 实现站立、呼吸、发丝和指针响应
    │
    ├─ live2d
    │    └─ live2d-plugin 动态加载 oh-my-live2d
    │
    └─ off
         └─ 不加载任何看板娘
```

### 文件清单

- `src/components/HomeChieMascot/`：主页生产组件与明暗主题样式。
- `src/data/chieMascot.js`：中英文对白、无障碍文案、素材名和交互映射。
- `static/img/chie/`：透明 WebP 立绘、表情、眨眼和头像。
- `src/components/ChieMascot/`：仅供内部预览页使用的调试组件。
- `src/pages/chie-preview.js`：未加入导航、带 `noindex,nofollow` 的预览页。
- `plugins/live2d-plugin/index.js`：仅在 `MASCOT_MODE=live2d` 时注册的旧方案。

### 响应式与加载规则

| CSS 视口宽度 | 展示 | 初始角色资源 |
| --- | --- | --- |
| `>= 1366px` | 右下角全身模型 | `chie-v2-idle.webp` |
| `1024–1365px` | 48px 头像按钮 | `chie-v2-avatar.webp` |
| `<= 1023px` | 完全隐藏 | 不请求角色图片 |

全身模式在浏览器空闲时预载 annoyed、shy、alert 和 blink；首次椅子待机前才加载 seated A 与坐姿眨眼素材。首次问候结束后等待 5–8 秒进入坐姿，后续循环等待 12–18 秒。坐姿持续 9 秒，左右小腿以膝盖为固定轴完成 3 秒连续插值周期；静态膝盖桥接层和裙摆细节层负责遮挡关节接缝。表情按 enter、hold、exit 三阶段切换，并通过眨眼过桥帧分别插值眼睛、嘴部与面部色调。页面滚动不会改变展示状态，只有游客点击收起按钮才会切换到头像；手动收起状态与首次问候只写入 `sessionStorage`，不会跨浏览器会话保留。

### 模式切换

`docusaurus.config.js` 读取 `MASCOT_MODE`，可选值为 `chie`、`live2d` 和 `off`，未设置时使用 `chie`。

```powershell
# 默认 CHIE
npm run build

# 临时切回旧 Live2D
$env:MASCOT_MODE = 'live2d'
npm run build

# 完全关闭看板娘
$env:MASCOT_MODE = 'off'
npm run build
```

### Live2D 回退方案

回退插件使用 `injectHtmlTags()` 注入一段内联初始化脚本。脚本在桌面端动态创建 oh-my-live2d v0.19.3 的 CDN `<script>`，加载成功后调用 `window.OML2D.loadOml2d()`；失败时只记录警告。模型仍是托管于 jsDelivr 的 Senko-san。

因此，默认 `chie` 与 `off` 构建中不会出现 oh-my-live2d CDN 请求。若未来改为 Cubism 自制模型，只需在 `live2d-plugin` 中替换模型入口和缩放参数，再以 `MASCOT_MODE=live2d` 验证，不影响当前 CHIE 上线版本。

## 五、如何开发与部署

```bash
# 开发服务器（localhost:3000，热更新）
npm start

# 生产构建
npm run build          # 输出到 build/
npm run serve          # 本地预览构建产物

# 类型检查
npm run swizzle        # 覆写主题组件

# 清理缓存
npm run clear
```

部署目标：Vercel（`@docusaurus/faster` 有 Vercel 原生支持），也可部署到 GitHub Pages。
